# NFS-e Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Emissor standalone de NFS-e no webservice da Prefeitura de São Paulo, layout v2 (reforma IBS/CBS), com UI React/shadcn e API genérica bearer token, deployável no Railway.

**Architecture:** FastAPI serve API REST e build estático do frontend. Domínio NFS-e monta XML v2 com lxml, valida contra XSD local, assina (string RPS v2 + XMLDSig enveloped) e envia SOAP com TLS mútuo. SQLite em volume guarda notas, config e senha cifrada do certificado.

**Tech Stack:** Python 3.12+, FastAPI, lxml, cryptography, requests, SQLAlchemy, bcrypt, itsdangerous, pytest. Frontend: Vite, React, TypeScript, Tailwind, shadcn (componentes via CLI).

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-30-nfse-design.md` (aprovado, seguir à risca)
- Endpoint webservice: `https://nfews.prefeitura.sp.gov.br/lotenfe.asmx` (único que aceita layout v2)
- Cabeçalho XML: `Versao=2`; namespace raiz `http://www.prefeitura.sp.gov.br/nfe`
- SOAP namespace: `http://www.prefeitura.sp.gov.br/nfe/ws/lotenfe`; envelope SOAP 1.1, `SOAPAction: ""`, MensagemXML em CDATA (padrão que funcionou em produção no emissor arquivado)
- String de assinatura RPS v2: inscrição 12 dígitos (v1 era 8), `ValorInicialCobrado` no lugar de `ValorServicos`, indicador tomador aceita 4 (NIF), campo 16 NIF/NaoNIF no fim. Vetores de teste oficiais do manual estão no Task 3
- XSDs oficiais da prefeitura em `backend/schemas/`
- PROIBIDO travessão (caractere em dash) em qualquer entregável: código, comentários, UI, docs. Grep antes de commitar
- Segredos apenas em `.env` / variáveis Railway: `ADMIN_USER`, `ADMIN_PASSWORD_HASH`, `API_TOKEN`, `SECRET_KEY`, `DATA_DIR` (default `/data`)
- Idioma de UI, mensagens e docs: português
- Cores do frontend: base preto/branco com uma cor primária de destaque
- Commits frequentes, mensagens em português, conventional commits
